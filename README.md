# AutoHub Docs

Документация системы СТО «Авто-Хаб».

Сайт: https://IggyKuz.github.io/AutoHub-Docs/

## Как добавить страницу

1. Создать файл `.md` в нужной папке `docs/`.
2. Добавить путь к файлу в `nav:` в `mkdocs.yml`.
3. Закоммитить — сайт обновится автоматически.

## Локальный запуск (необязательно)

```bash
pip install -r requirements.txt
mkdocs serve
