# 6.1. Нефункциональные требования

В данном разделе приведены ключевые нефункциональные требования (NFR) к системе **AutoHub**, обеспечивающие надежность, производительность и безопасность в рамках бюджета и сроков MVP.

### Список измеряемых требований (MVP)

1. **Время отклика интерфейса (Производительность)**  
   Время выполнения базовых операций (открытие заказ-наряда, поиск клиента по VIN/телефону, сохранение данных) не должно превышать **2 секунд** при 95-м перцентили нагрузочных запросов.

2. **Доступность системы (Availability)**  
   Коэффициент доступности веб-приложения должен составлять не менее **99.0%** в рабочее время СТО (с 08:00 до 21:00 по московскому времени), исключая запланированные окна технического обслуживания.

3. **Совместимость с клиентами (Compatibility)**  
   Веб-интерфейс АРМ Менеджера и Мастера должен корректно отображаться и функционировать в актуальных версиях браузеров **Google Chrome (v110+)** и **Yandex Browser (v23+)** при минимальном разрешении экрана **1280×720**.

4. **Аутентификация и права доступа (Безопасность)**  
   Система должна обеспечивать ролевую модель доступа (РМД) с явным разделением прав: менеджер не имеет доступа к администраторским настройкам, а мастер — к финансовым отчетам. Сессия пользователя автоматически завершается после **15 минут** бездействия.

5. **Резервное копирование данных (Надежность)**  
   Создание резервных копий (backup) базы данных должно производиться автоматически **1 раз в сутки** в ночное время. Время восстановления базы данных из бекапа (RTO) не должно превышать **2 часов**, потеря данных (RPO) — не более **24 часов**.

6. **Максимальная пиковая нагрузка (Масштабируемость)**  
   Система должна устойчиво обрабатывать одновременную работу до **50 активных пользователей** (менеджеров/мастеров) без деградации времени отклика свыше 3 секунд.

7. **Простота и скорость освоения (Удобство использования)**  
   Интерфейс оформления визита и создания заказ-наряда должен быть спроектирован так, чтобы обученный сотрудник выполнял ввод данных нового клиента и авто не более чем за **3 минуты** (проверяется на приемочных испытаниях).
