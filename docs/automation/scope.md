# 4.1. Предмет разработки

Предметом разработки является веб-ориентированная система автоматизации сети СТО «AutoHub». Система включает в себя клиентский модуль онлайн-записи, рабочие места (UI) для менеджеров, мастеров ремзоны, сотрудников склада и руководства, а также подсистему учёта выполненных работ, расчёта выработки персонала и интеграцию с CRM.
