# 4.2. Сведения о пользователях

Основными пользователями системы являются:

* **Клиент:** автовладелец, оформляющий запись на обслуживание, отслеживающий статус ремонта и согласовывающий перечень работ.
* **Менеджер по работе с клиентами:** сотрудник СТО, осуществляющий прием заявок, распределение клиентов по боксам и мастерам, а также координацию взаимодействия с клиентом.
* **Мастер СТО:** специалист ремзоны, фиксирующий фактически выполненные работы, затраченные норма-часы и формирующий запросы на доп. работы.
